# Documentation map

Start with the repository root [`README.md`](../README.md), then follow the
authoritative read order in [`AGENTS.md`](../AGENTS.md).

## Canonical product authority

- [`PRD.md`](PRD.md) — AI-LIT requirements and the preserved, paused MY5 baseline.
- [`DECISION_LOG.md`](DECISION_LOG.md) — shared and project-specific decisions.
- [`project-index.json`](project-index.json) — machine-readable routing and provenance.

## Supporting documentation

- [`operations/`](operations/) — current deployment and secret-management procedures.
- [`design/`](design/) — design guidance and architecture briefing material.
- [`reviews/`](reviews/) — dated reviews that do not override the canonical documents.
- `research/` — reserved for source-grounded research when that directory exists.
- [`evidence/`](evidence/) — preserved evidence with explicit status and provenance.
- [`archive/`](archive/) — historical instructions retained for context, not execution.

Supporting and archived documents never override the canonical PRD, decision log,
or current agent instructions.
