# Evidence

Evidence is preserved with source identity and explicit status. Its presence does
not turn it into a current requirement, approval, release gate result or reuse
permission.

- [`manifests/recovered-replit-assets.v1.json`](manifests/recovered-replit-assets.v1.json)
  records the exact build assets recovered from the Replit checkpoint.
- [`manifests/legacy-main-screenshots.v1.json`](manifests/legacy-main-screenshots.v1.json)
  records historical screenshots moved from the repository root.
