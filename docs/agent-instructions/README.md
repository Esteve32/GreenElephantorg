# Supplemental agent instructions

The file beside this README is a pinned copy of the
[Esteve AI Literacy Training Seed](https://github.com/Esteve32/esteve-ai-literacy-training-seed/blob/a874a4fb5ca375814c6d5faff35de574f5057c30/bundles/%F0%9F%8D%82%20Esteve%20AI%20Literacy%20Training%20Seed/%F0%9F%8D%82%20Agent%20Instructions.md).

## Developer switch

The supplemental instructions are enabled by default. To disable them for this
repository, set seed_instructions.enabled to false in docs/agent-settings.yml.
This does not disable AGENTS.md, Copilot/Replit instructions, safety rules, or
the source-of-truth and approval boundaries for this repository.

## First use

When enabled, use the seed's five-question setup only if the person's preferences
are not already known. Keep personal answers in the person's AI settings, never
in Git. The repository snapshot is pinned to source commit
a874a4fb5ca375814c6d5faff35de574f5057c30; update it only through review.
